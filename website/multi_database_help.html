🔐 راهنمای استفاده همزمان از چند دیتابیس

⚠️ مشکل تداخل Session

به دلیل ساختار Odoo، استفاده همزمان از چند دیتابیس در یک مرورگر ممکن است باعث تداخل session ها شود. وقتی در یک مرورگر به دو دیتابیس مختلف لاگین می‌کنید، session آخر جایگزین session قبلی می‌شود.

✅ راه‌حل‌های پیشنهادی

برای استفاده همزمان از چند دیتابیس، از یکی از روش‌های زیر استفاده کنید:

روش ۱: استفاده از مرورگرهای مختلف

ساده‌ترین روش این است که هر دیتابیس را در یک مرورگر جداگانه باز کنید:

🌐 Google Chrome

دیتابیس اول

🦊 Firefox

دیتابیس دوم

🎯 Microsoft Edge

دیتابیس سوم

روش ۲: استفاده از حالت ناشناس (Incognito/Private)

می‌توانید در همان مرورگر از پنجره‌های ناشناس استفاده کنید:

  • پنجره عادی: دیتابیس اول
  • پنجره ناشناس ۱: دیتابیس دوم (Ctrl+Shift+N در Chrome)
  • پنجره ناشناس ۲: دیتابیس سوم (پنجره جدید ناشناس)

روش ۳: استفاده از پروفایل‌های جداگانه

در Google Chrome:

  1. روی آیکون پروفایل در گوشه بالا کلیک کنید
  2. گزینه "Add" یا "افزودن پروفایل" را انتخاب کنید
  3. یک پروفایل جدید با نام شرکت مورد نظر بسازید
  4. هر دیتابیس را در پروفایل مجزا باز کنید

روش ۴: استفاده از Container های Firefox

اگر از Firefox استفاده می‌کنید، از افزونه Multi-Account Containers استفاده کنید:

  • افزونه را از Firefox Add-ons نصب کنید
  • برای هر دیتابیس یک Container جداگانه بسازید
  • هر لینک دیتابیس را در Container مربوطه باز کنید

💡 نکات مهم

  • همیشه از لینک کامل دیتابیس با پارامتر ?db=نام_دیتابیس استفاده کنید
  • در صفحه اطلاعات دیتابیس، لینک اختصاصی دیتابیس خود را کپی کنید
  • از Bookmark کردن لینک‌های کامل استفاده کنید تا مشکل کمتری پیش بیاید
  • هر دیتابیس را در یک محیط جداگانه (مرورگر/پروفایل/Container) باز کنید

🎯 توصیه برای استفاده حرفه‌ای

اگر نیاز دارید به صورت مداوم با چندین دیتابیس کار کنید، توصیه می‌کنیم:

  • برای هر مشتری/پروژه یک پروفایل مرورگر اختصاصی بسازید
  • لینک‌های دیتابیس‌ها را در Bookmark Manager سازماندهی کنید
  • از رنگ‌بندی و آیکون‌های متفاوت برای تشخیص سریع استفاده کنید
