امن و مطمئن

همه فایل‌ها از منابع رسمی دانلود می‌شوند

مرحله ۱: دانلود نصاب

۱

دانلود فایل ZIP نصاب

از بخش "دانلود نصاب" در همین داشبورد، فایل ZIP را دانلود کنید. این فایل فقط 130KB است!

نکته: نصاب رایگان است و نیازی به لایسنس برای دانلود ندارید.
۲

Unblock کردن فایل ZIP

ویندوز ممکن است فایل‌های دانلود شده را بلاک کند. این کار را انجام دهید:

  1. روی فایل ZIP راست‌کلیک کنید
  2. گزینه Properties را انتخاب کنید
  3. در پایین پنجره، تیک Unblock را بزنید
  4. روی OK کلیک کنید
مهم: اگر این کار را نکنید، ممکن است برنامه درست اجرا نشود!
۳

استخراج (Extract) فایل

فایل ZIP را در یک مسیر ساده (بدون فاصله و حروف فارسی) Extract کنید.

C:\OdooMaster یا D:\Odoo
از مسیرهایی مثل C:\Users\علی\Desktop استفاده نکنید!

مرحله ۳: اجرای نصاب

۱

اجرای نصاب

وارد پوشه Extract شده شوید و فایل زیر را اجرا کنید:

start_ui_online.bat
اگر آنتی‌ویروس هشدار داد، Allow یا اجازه بدهید.
۲

شناسه سخت‌افزاری (Hardware ID)

نصاب یک شناسه سخت‌افزاری منحصربه‌فرد برای سیستم شما نمایش می‌دهد. این شناسه برای فعال‌سازی لایسنس لازم است.

مثال: A1B2C3D4E5F6G7H8
۳

شروع چک سیستم

روی دکمه "شروع بررسی سیستم" کلیک کنید. نصاب موارد زیر را بررسی می‌کند:

  • نسخه ویندوز
  • Python نصب شده یا خیر
  • PostgreSQL نصب شده یا خیر
  • Git نصب شده یا خیر
  • Node.js نصب شده یا خیر
۴

نصب نیازمندی‌ها

اگر چیزی نصب نباشد، دکمه "نصب نیازمندی‌ها" ظاهر می‌شود. با کلیک روی آن، نصب خودکار شروع می‌شود.

این مرحله بسته به سرعت اینترنت، ممکن است 10 تا 30 دقیقه طول بکشد.

مرحله ۴: فعال‌سازی لایسنس

۱

کپی کردن شناسه سخت‌افزاری

از نصاب، شناسه سخت‌افزاری را کپی کنید.

۲

خرید لایسنس

به بخش "خرید لایسنس" در داشبورد بروید و با وارد کردن شناسه سخت‌افزاری، لایسنس بخرید.

رفتن به صفحه خرید
۳

دانلود فایل لایسنس

پس از خرید، فایل لایسنس (.oml) را دانلود کنید.

۴

قرار دادن فایل لایسنس

فایل لایسنس را در همان پوشه‌ای که نصاب هست قرار دهید (کنار فایل start_ui_online.bat).

C:\OdooMaster\license.oml
۵

نصب Odoo!

حالا نصاب را مجدد اجرا کنید. با داشتن لایسنس معتبر، می‌توانید Odoo را نصب کنید.

تبریک! پس از نصب، Odoo در آدرس http://localhost:8069 در دسترس خواهد بود.

رفع مشکلات رایج

نصاب اجرا نمی‌شود یا بسته می‌شود
  • مطمئن شوید فایل ZIP را Unblock کرده‌اید
  • نصاب را Run as Administrator اجرا کنید
  • آنتی‌ویروس را موقتاً غیرفعال کنید
  • مسیر نصب نباید حروف فارسی یا فاصله داشته باشد
خطای نصب Python
  • اگر Python قبلاً نصب است، آن را Uninstall و دوباره نصب کنید
  • حتماً گزینه Add to PATH را تیک بزنید
  • بعد از نصب، سیستم را Restart کنید
خطای نصب PostgreSQL
  • پورت پیش‌فرض 5432 باید آزاد باشد
  • رمز عبور را ساده انتخاب کنید (مثل: odoo)
  • اگر PostgreSQL قبلی نصب است، آن را کامل حذف کنید
Odoo اجرا نمی‌شود
  • PostgreSQL باید در حال اجرا باشد (سرویس آن را چک کنید)
  • پورت 8069 نباید توسط برنامه دیگری استفاده شود
  • فایروال ویندوز ممکن است مسدود کرده باشد
لایسنس شناسایی نمی‌شود
  • فایل لایسنس باید دقیقاً کنار نصاب باشد
  • نام فایل را تغییر ندهید
  • شناسه سخت‌افزاری باید با سیستم فعلی مطابقت داشته باشد
  • لایسنس منقضی نشده باشد
نیاز به کمک بیشتر دارید؟

با پشتیبانی ما تماس بگیرید یا از بخش تیکت‌ها سوال خود را مطرح کنید.
